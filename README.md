# SQL Playground

SQL exercises solved with SQL Server and the AdventureWorks2025 database.

## Goal
To practice SQL from beginner to intermediate level, as part of my learning path
toward working with databases and Power BI.

## Technologies
- SQL Server 2025 Express
- SQL Server Management Studio (SSMS)
- Sample database: AdventureWorks2025 (Microsoft)
- Git and GitHub

## Structure

| Folder | Content | Status |
|--------|---------|--------|
| `01_select/` | SELECT, WHERE, ORDER BY, LIKE, IN, DISTINCT, IS NULL | ✅ Done |
| `02_aggregations/` | COUNT, SUM, AVG, MAX, MIN, GROUP BY, HAVING | ✅ Done |
| `03_joins/` | INNER JOIN, LEFT JOIN | 🔄 In progress |
| `04_subqueries/` | Subqueries, EXISTS | ⏳ Next |
| `05_functions/` | Dates, strings, CASE WHEN | ⏳ Next |

## How to run
1. Install SQL Server Express and SSMS.
2. Download AdventureWorks2025.bak from Microsoft's website and restore it in SSMS.
3. Open the `.sql` files and run them with `USE AdventureWorks2025;` at the top.

## About me
Studying to become a Data / BI Analyst. Next steps: Power BI and the PL-300
certification.
